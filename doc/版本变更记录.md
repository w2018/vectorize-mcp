## 🔴 更新本文档时必须遵守的结构约束（强制）

1. **倒序**：新条目**插到版本区顶部**（最新在最前），**禁止**追加到末尾。
2. **标题**：`## vX.Y.Z ｜ YYYY-MM-DD —— 一句话主题`（主题 ≤ 40 字，细节写进正文）。
3. **分类标签**：每条变更必须以 `[新增]` `[优化]` `[修复]` `[破坏性变更]` 之一开头；
   `[说明]` 仅限**出包号 / 兼容性提示**等元信息，且每个条目最多 1 条。
4. **一条一要点**：每条 **≤ 3 行**，只写「问题 → 结论/做法」，**不写**推导过程与验证输出。
5. **禁止冗余**（违反即视为未完成）：
   - 不写构建/检查结果（`vue-tsc` / `lint` / `cargo check` 通过等）；
   - 不写「沙箱无显示器 / 待真机确认」（见下方通用约定）；
   - 不写「未推送 / 未打标签 / 未触发 CI」（只在发布条目里写一次）；
   - 不重复他条已写过的内容 —— 写「详见 vX.Y.Z」即可；
   - 不贴命令输出、日志片段、实测 JSON。
6. **出包号**写在正文首行：`**出包**：文件包名_版本号.后缀`。

## 通用约定（各条目不再重复）

- 🔴 **GUI 交互**：沙箱无显示器，交互/手感**必须由用户真机确认** —— 不得声称已验证交互。
- 🔴 **发布纪律**：默认只本地提交；`git push` / 打标签 / 触发 CI **需用户逐次明确许可**。
- 🔴 **改动时**：前端 / 后端 / 侧车任一处改动都**必须重新出包**才生效。


## v0.1.3 ｜ 2026-11-05 —— 回收站、3D 星图与统计增强

**出包**：vectorize-mcp_0.1.3（源码仓库，未构建独立安装包）

- [新增] **回收站**：记忆与已撤销凭据删除后进入独立 SQLite 快照库，支持单条/批量恢复、永久删除及批量清理。

- [新增] **3D 记忆星图**：持续旋转与拖拽、滚轮缩放、悬停高亮和键盘选择，遵循减少动态效果偏好。
- [新增] **统计扩展**：新增记忆总数/内容 token/提取 token/有效命中率，并提供按账户维度的独立统计。
- [新增] **关于页**：侧边栏底部展示作者 w2018、版本 0.1.3、开源地址与 MIT 协议。
- [优化] **操作反馈**：Web 管理操作统一二次确认，覆盖成功、取消、失败三种结果；归档、取消归档与删除同步刷新列表与统计。
- [优化] **MCP 静默写入**：新增、修改、归档成功仅返回 {"ok":true}；待审核相似候选保留完整结果，不伪装成功。
- [修复] **数据一致性**：修正删除/恢复跨库提交边界、批内重复内容与合并引用校验，避免恢复唯一约束失败或快照误删。

## v0.1.0 ｜ 2026-11-05 —— 首版统一 MCP 长期记忆服务

**出包**：vectorize-mcp_0.1.0（源码仓库，未构建独立安装包）

- [新增] **MCP 统一接口**：HTTP 与 stdio 桥接，Bearer 鉴权、账户隔离、撤销后保留数据并可重签。
- [新增] **记忆能力**：查增改、组合去重、revision 冲突、幂等重试、画像与关联召回，结果合计 0～5 条。
- [新增] **SQLite 存储**：单写多读 worker、有界队列、主业务库与独立观察日志库，检索计数原子提交。
- [新增] **中文后台**：记忆、画像、关系星图、统计、设置、导入导出、备份恢复与审计。
- [新增] **编码与降级**：OpenAI 兼容 embeddings，未配置或失败时明确降级词法检索，不生成伪向量。
- [优化] **弱网重试**：桥接器有限抖动重试保持原 request_id 与参数，业务错误不自动重试。
- [修复] **写入边界**：SQL 触发器拒绝跨账户/跨空间写入与陈旧向量，恢复主库后旧凭据失效。
- [说明] 仓库仅提交 README 与源码；测试脚本与本地设计文档存放 `tmp/`，不进入版本控制。

## 附录（接手/继续开发先读）

- **架构**：单实例 Node.js；Fastify 提供 HTTP 与 `/mcp`；DatabasePool 一写两读 worker；better-sqlite3 + sqlite-vec；React/Vite 后台由构建产物托管。
- **出包**：`npm ci && npm run build` 生成 `dist/server/main.js` 与 `dist/web`；前端或后端改动都必须重新构建；可用 Dockerfile 打包。
- **扩展清单**：新增 MCP 工具改 `src/mcp/schemas.ts` 与 `src/mcp/http.ts`；领域存储改 `src/core/store.ts`；管理路由改 `src/server/admin.ts`；页面改 `src/web/`。
- **排错速查**：启动失败查 `data/admin-password.json` 与陈旧 `.instance-lock`；MCP 401 查 Token；检索退回词法查 `EMBEDDING_*` 与后台设置；端口占用改 `PORT`。
